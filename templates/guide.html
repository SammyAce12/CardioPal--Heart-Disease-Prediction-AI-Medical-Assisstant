Easy Guide

How to fill the heart form

This page explains every box in simple words. You can follow it one line at a time and type the number you see from your age, home device, or hospital paper.

Simple rule

If you do not know a value, stop there and ask a nurse, doctor, or health worker. It is better to use the correct number than to guess.

1

Age

Type your age in years.

Example: `45`

2

Sex

Type `1` for male. Type `0` for female.

Male = `1`, Female = `0`

3

Chest Pain Type

This number describes the kind of chest pain written on a hospital report.

Usually a number from `0` to `3`

4

Blood Pressure

Type the top blood pressure number from your BP machine or clinic result.

Example: `120`

5

Cholesterol

Type the cholesterol number from your blood test paper.

Example: `200`

6

Fasting Blood Sugar

This box asks if fasting blood sugar is above 120.

High = `1`, Normal = `0`

7

EKG Results

Type the EKG result number shown on your test sheet.

Usually `0`, `1`, or `2`

8

Maximum Heart Rate

Type the highest heart rate from an exercise test or clinic report.

Example: `150`

9

Exercise Angina

This means chest pain during exercise.

Yes = `1`, No = `0`

10

ST Depression

Type the ST depression number exactly as it appears on the medical result.

Example: `1.5`

11

Slope of ST

Type the slope number from the report.

Usually `0`, `1`, or `2`

12

Number of Vessels

This is the number of major blood vessels colored in the test result.

Usually `0` to `3`

13

Thallium Test

Type the thallium result from the report.

Common values: `3`, `6`, `7`

Before you press predict

Check each box slowly. Make sure numbers match your hospital paper. If one value is missing, ask for help before submitting.
