## 🌍 Overview

**CardioPal** is a smart healthcare web application that uses **Machine Learning** to predict the risk of heart disease based on user health data.

It combines:

* 🧠 AI predictions
* 🎨 Modern UI/UX
* 🔊 Voice assistance
* 🌍 Multilingual support

👉 Built to be **accessible, fast, and user-friendly**, even for non-literate users.

## 🧠 Machine Learning

| Component     | Details                                  |
| ------------- | ---------------------------------------- |
| Algorithm     | Random Forest                            |
| Accuracy      | ~85% – 90%                               |
| Training Data | Heart Disease Dataset + Extended Dataset |
| Output        | Binary Classification + Risk Probability |

## ⚙️ Installation Guide

### 🔹 1. Clone Repository

```bash
git clone https://github.com/SammyAce12/CardioPal--Heart-Disease-Prediction-AI-Medical-Assisstant
cd CardioPal
```

---

### 🔹 2. Create Virtual Environment

```bash
python -m venv venv
venv\Scripts\activate
```

---

### 🔹 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

### 🔹 4. Train Model (Optional)

```bash
python train_heart_model.py
```

---

### 🔹 5. Run App

```bash
python app.py
```

---

### 🔹 6. Open in Browser

```
http://127.0.0.1:5000
```

## 📊 How It Works

1. User logs into system
2. Inputs health parameters
3. ML model processes input
4. Prediction + risk % generated
5. Result displayed with visual feedback
6. Data saved for history tracking
